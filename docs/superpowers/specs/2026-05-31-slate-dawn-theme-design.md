# Slate Dawn 浅色主题替换设计

**日期：** 2026-05-31  
**状态：** 已批准  

---

## Context

当前界面使用 "Tokyo Twilight" 深色主题（深蓝底色 + 珊瑚红强调色）。用户希望将其完全替换为 "Slate Dawn" 浅色主题（浅灰白底色 + 靛蓝强调色），不保留旧主题，不添加主题切换开关。

---

## 方案

完全替换：修改 `resources/style.qss` 与 `src/SqlHighlighter.cpp` 中的全部颜色值，将深色调替换为浅色调。无需新增文件或修改架构。

---

## 涉及文件

- `resources/style.qss` — 全量替换所有颜色值
- `src/SqlHighlighter.cpp` — 替换 7 处颜色定义

不需要改动 C++ 布局代码、CMakeLists.txt 或 QRC 文件。

---

## 验证方式

1. 编译并运行 `DataManagement_System.exe`
2. 检查：主窗口背景为浅灰白、SQL 编辑器为白底、执行按钮为靛蓝色
3. 输入 SQL（如 `SELECT * FROM studentTable`）执行，验证：
   - 语法高亮关键字为靛蓝、列名为深蓝、表名为琥珀棕
   - 结果表格背景白底、选中行为浅蓝紫色
4. 触发错误 SQL，验证错误下划线为深红色
5. 检查 Schema 树、分页栏、滚动条、对话框均无深色残留
